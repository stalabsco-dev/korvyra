# 02. Requisitos funcionales

- El usuario podrá consultar un panel de estado.
- El usuario podrá configurar fuentes y canales cuando las integraciones estén disponibles.
- La plataforma deberá distinguir alertas nuevas, leídas y fallidas.
- Se priorizará la notificación de directos de Kick.
- Se documentará claramente qué fuentes están conectadas y cuáles son demostrativas.
