# 03. Arquitectura

## Enfoque
Aplicación web progresiva (PWA), con interfaz adaptable a móviles y una arquitectura que permita separar presentación, lógica de negocio e integraciones.

## Componentes previstos
- Frontend web.
- API/backend para usuarios, preferencias y eventos.
- Adaptadores independientes por plataforma.
- Sistema de tareas programadas y entrega de notificaciones.
- Almacenamiento de configuración y eventos.

La selección definitiva de backend y proveedores se realizará tras validar límites gratuitos, seguridad y términos de cada plataforma.
