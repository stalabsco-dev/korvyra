# 04. Integraciones externas

## Kick
Objetivo prioritario: detectar el inicio de transmisiones en vivo de canales seguidos. Se utilizarán únicamente interfaces oficiales o métodos permitidos.

## YouTube
Objetivo: detectar nuevos videos mediante mecanismos oficiales disponibles.

## TikTok
Objetivo: detectar publicaciones y directos cuando exista una API o integración permitida que cubra el caso.

## Reglas
- No almacenar contraseñas de plataformas externas.
- Proteger tokens mediante variables de entorno y almacenamiento seguro.
- Respetar cuotas, permisos, términos y límites de cada proveedor.
- Mostrar errores de integración sin simular alertas reales.
