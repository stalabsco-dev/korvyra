# 07. Hoja de ruta

## Fase 0 — Fundamentos
Documentar visión, alcance, requisitos, arquitectura prevista, integraciones, seguridad, diseño y hoja de ruta.

## Fase 1 — Base técnica
Crear la aplicación web inicial, configuración de desarrollo, estructura frontend y primera interfaz adaptable a móviles.

## Fase 2 — Backend y persistencia
Definir API, almacenamiento, configuración y gestión de eventos.

## Fase 3 — Integraciones
Implementar y probar fuentes externas, priorizando avisos de directos de Kick.

## Fase 4 — Notificaciones
Añadir preferencias, entrega, reintentos y registro de errores.

## Fase 5 — Pruebas y lanzamiento
Validar seguridad, accesibilidad, rendimiento, límites de proveedores y despliegue.

Cada fase requiere revisión y aprobación antes de continuar.
