# KORVYRA

Proyecto `korvyra`.

KORVYRA es una plataforma mobile-first de monitoreo digital y alertas. Este paquete contiene la documentación de la Fase 0; todavía no es una aplicación funcional.

## Restricciones

- Administración y desarrollo desde Android.
- Sin PC, Codespaces ni máquinas virtuales que el usuario tenga que administrar.
- Presupuesto inicial objetivo: $0 MXN, respetando cuotas gratuitas.
- PWA en español, adaptable a móviles.
- Kick es la plataforma requerida para alertas de inicio y fin de directos.
- No prometer acceso universal ni alertas instantáneas si las APIs no lo permiten.

Consulta `docs/` para conocer el alcance, arquitectura, integraciones, costos, seguridad, hoja de ruta y decisiones.
