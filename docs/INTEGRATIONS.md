# Integraciones y límites
## Kick — prioridad obligatoria
Detectar inicio y fin de directos mediante mecanismos oficiales disponibles, como eventos/webhooks de estado de livestream si el acceso está habilitado.
- Confirmar documentación, permisos y registro vigentes.
- Validar firmas según documentación oficial.
- Evitar eventos duplicados.
- No asumir monitoreo universal sin acceso o autorización.
- No prometer tiempos de entrega garantizados.

## YouTube
Usar mecanismos oficiales y respetar cuotas. Notificaciones de nuevos videos no garantizan detectar cada inicio de YouTube Live.

## TikTok
Depende de APIs oficiales, revisión, permisos y autorización. No presentarlo como monitoreo universal de cualquier cuenta.

## Temas y fuentes web
Priorizar RSS/Atom, APIs públicas y fuentes que permitan automatización. Respetar términos, robots, límites y derechos de autor. Guardar metadatos, enlaces y extractos breves.

Cada adaptador debe incluir validación, deduplicación, reintentos limitados, control de cuotas y registro de estado. Si una API no ofrece una capacidad, mostrarla como limitada o no disponible; nunca simularla.
