# Seguridad y privacidad
- Nunca colocar API keys, tokens o contraseñas en el frontend o repositorio.
- Guardar secretos en el entorno seguro del backend.
- Validar permisos en servidor y aislar datos por usuario.
- Verificar firmas de webhooks y rechazar eventos inválidos.
- Usar HTTPS, límites de frecuencia y dependencias actualizadas.
- Registrar errores sin tokens ni datos sensibles.
- Recopilar solo datos necesarios y ofrecer mecanismos de eliminación.
- Respetar leyes, términos de plataformas y derechos de autor.
